# Instrucciones
1. Recopila la descripcion del proyecto y define Functional Requirements (FR-xxx).
2. Estructura Acceptance Scenarios bajo formato Given / When / Then con valores numericos concretos.
3. Enumera los Edge Cases explicitos y la seccion Clarifications.
4. Escribe el archivo en specs/<nombre-feature>/spec.md.
